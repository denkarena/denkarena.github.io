Stockfish in DenkArena

DenkArena enthält für die Partie-Analyse die Schach-Engine Stockfish 19 in der WebAssembly-Fassung Stockfish.js 19.0.1 „Lite, single-threaded“. Stockfish ist freie Software unter der GNU General Public License Version 3. DenkArena includes the chess engine Stockfish 19 (WebAssembly build Stockfish.js 19.0.1 "Lite, single-threaded") for game analysis. Stockfish is free software under the GNU General Public License version 3. It is included unmodified and runs as a separate program; DenkArena only exchanges chess commands with it via the UCI protocol.
